# lspy

> Реализация протокола LocalSend в командной строке. Один файл, без сторонних зависимостей: LocalSend на телефоне, одна команда на компьютере. Есть ретрансляция между сетями через ntfy.sh.

## ✨ Основные возможности

- **Два поколения протокола**: LocalSend `v2` (`prepare-upload`/`upload`/`cancel`) и `v2.1` (`send-request`/`send`); префикс `v1` тоже работает. Автоматический откат при 404/405.
- **Тройное обнаружение**: multicast `224.0.0.167:53317`, широковещание подсети и **глубокое HTTP-сканирование** (все интерфейсы, оба порта параллельно).
- **Докачка без перезаписи**: продолжение с дискового смещения; имена проходят `safe_filename` + `unique_path`, конфликты получают `(1)`.
- **Контроль доступа**: PIN (`401` требуется/неверный, `429` после 3 ошибок с одного IP — как в LocalSend), белые/чёрные списки отпечатков, фильтр опасных расширений (пропуск по файлам).
- **Защита от Zip Slip**: отклоняются абсолютные пути, буквы дисков, обход `..` и символические ссылки.
- **TLS**: `lspy cert` создаёт самоподписанную пару; обе стороны могут работать через HTTPS.
- **Между сетями**: через ntfy.sh, блоки по 2400 байт, 3 попытки, завершающий SHA-256.
- **Веб-страница обмена** (загрузка / скачивание / текст, портирована из watchsend; страница следует `Accept-Language` браузера), **10 языков интерфейса**.
- **sha256 для каждого файла** (как в `createChecksums` / `verifyChecksums`): отправитель кладёт хеш файла в `files[].sha256`, а получатель с включённым `verify_checksum` проверяет его так же, как официальный клиент — при расхождении `422 Checksum mismatch`, сохранённый файл удаляется. При отправке по обычному HTTP дополнительно предупреждаем, что трафик не шифруется.
- **Диагностика сети** (из официальной `troubleshoot_page`): `lspy troubleshoot` или пункт `9` проверяет, можно ли слушать порт, выводит локальные адреса (сначала IPv4, `fe80`-адреса скрыты), печатает правило брандмауэра Windows `netsh advfirewall ... localport=` и напоминает, что HTTP-скан работает и при блокировке мультикаста изоляцией точки доступа.
- **Случайный псевдоним и настраиваемый облик устройства** (как `alias_generator` и `deviceType` / `deviceModel`): при первом запуске создаётся псевдоним «прилагательное + фрукт» и сохраняется, поэтому имя хоста больше не уходит в локальную сеть; `device_type` / `device_model` задают тип и модель в `info`, их же меняют пункты 11 и 12 настроек.
- **История и отладка** (тоже из watchsend): `history --delete N` / `--clear` / `--unzip N` (ZIP помечен 📦, защита от Zip Slip), `--debug-keys` показывает исходные ключи i18n.
- **Мелкие удобства при получении**: полученные `.txt` до 10 КБ сразу попадают в буфер обмена (отключается через `clipboard_text`), история обрезается по `history_max` (по умолчанию 300), а `info` дополнительно печатает `[IPv6]:порт`.
- **Выбор файлов без tkinter**: встроенный [cfdialog](https://github.com/styisme/cfdialog) 0.3.0 (MIT, один файл) заменяет диалог tkinter на терминальный браузер (номера, `g` разделы, `h` скрытые файлы, `a`/`c`/`d` множественный выбор); `?` в настройке папки приёма открывает обзор папок. `config --set force_cfdialog=true` принудительно включает терминальный браузер (tkinter не используется). В Android tkinter пропускается (Tk там обычно нет), браузер открывается сразу.

---
- **Приём с любого экрана**: любая точка ввода (меню, настройки, выбор файлов) следит за очередью входящих передач и сразу показывает запрос на приём. При включённом `auto_accept` подтверждение пропускается и сразу открывается детализация приёма; после завершения Enter возвращает на прежний экран.
- **Остаться после отправки**: завершённая отправка больше не закрывается мгновенно - Enter возвращает в меню.

## 📱 Быстрый старт

```bash
git clone https://github.com/styisme/lspy.git
cd lspy
python lspy.py --help          # без установки
pip install .                  # установить команду `lspy`

lspy serve --web
lspy scan
lspy send a.jpg --ip 192.168.1.20:53317 --pin 1234
lspy cross-send photo.zip
```

Python 3.8+, без зависимостей. Откройте TCP/UDP `53317`.

## 🛠️ Сборка и тесты

```bash
pip install .
python -m unittest discover -s tests -v
python scripts/sync_version.py --check
pip install pyinstaller && python scripts/build_binary.py
```

Без Python: автономный файл из [Releases](https://github.com/styisme/lspy/releases) — Windows `lspy-<версия>-windows-x64.exe`, Linux `lspy-<версия>-linux-x86_64`.

Пуш изменения `CHANGELOG.md` в `main` собирает бинарники под Windows и Linux и автоматически создаёт тег и Release вместе с wheel и sdist.

## 🚧 Риски и ограничения

1. **Высокая доля ИИ**: протокол, проверки безопасности и скрипты CI созданы при участии ИИ; обязательны человеческое ревью и проверка на реальных устройствах. Это не аудированная реализация.
2. **Межсетевой канал — открытый текст**: тема ntfy и есть PIN; утёк PIN — утёк файл. Не передавайте конфиденциальные данные.
3. **Однофайловая архитектура**: `lspy.py` около 1500 строк; удобно распространять, но слабая модульность и статический анализ.
4. **Самоподписанный TLS**: цепочки сертификатов не проверяются, защиты от MITM нет.
